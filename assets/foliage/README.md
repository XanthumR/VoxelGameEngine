# Foliage models

The trees, bushes, rocks, logs and flowers of the islands, generated by
`tools/foliage/generate.py` (run it from the repository root; it overwrites every file here).
Where each grows, and how often in forests and in meadows, is the table `FOLIAGE_KINDS` in
`src/World/Foliage.h`; a new model needs a line there.

- **Frame:** x and y odd, the root (where it stands) in the middle column; z up, z = 0 is the
  ground layer: a trunk or rock there replaces the grass voxel, plants start at z = 1.
- **Turns:** the game stamps each model in one of four quarter turns, picked per spot.
- **Palette:** palette index = block ID. The foliage colors are 193-222 (`FOLIAGE_*` in
  `src/World/BlockTypes.h`, `FOLIAGE_PALETTE` in `shaders/render/shade.comp`): barks, birch bark,
  four leaf greens, needles, moss, three rock greys, blossoms, berries, flowers, palm fronds and
  trunk, banana leaf, agave, hibiscus, coconut, mushroom, dead wood. The building colors work too.

| Class | Old World | New World |
|---|---|---|
| Tree (wood for lumberjacks) | `oak`, `beech`, `birch`, `spruce` (2 each) | `palm_1-3`, `jungle_tree_1` |
| Bush | `bush_1-3` | `banana_1`, `monstera_1-2`, `agave_1` |
| Rock | `boulder_1-3` (both worlds) | |
| Log | `log_1-2`, `stump_1` | `palm_log_1`, `driftwood_1` |
| Flower | `flowers_1-3`, `fern_1-2` | `hibiscus_1`, `tropical_fern_1` |
